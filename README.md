# Нарды — коллекционная игра

Адаптивная игра в длинные и короткие нарды, а также гипергаммон. Можно играть вдвоём на одном устройстве или против локального ИИ.

## Запуск

Откройте сайт по HTTPS на телефоне или компьютере. Для установки на iPhone используйте Safari → «Поделиться» → «На экран Домой»; на Android — Chrome → меню → «Установить приложение». После первой загрузки игра может запускаться офлайн.

## Возможности

- Бросок кубиков нажатием на объёмные кости в центре доски.
- Длинные и короткие нарды, гипергаммон, таймеры и матчи.
- Передача телефона между двумя игроками с экраном скрытия доски.
- Коллекционные доски, фишки, кости и достижения, сохраняемые локально в браузере.
- Поддержка портретной и альбомной ориентации.
